# Paula Vieira — Design Gráfico & Social Media

![Paula Vieira Portfolio](https://i.ibb.co/qM3bLS2b/Woman-working-on-social-media-202605011152.jpg)

Portfólio premium desenvolvido para **Paula Vieira**, Social Media e Designer Gráfica. O projeto utiliza uma estética editorial de alta sofisticação, focada em converter visitantes em clientes através de uma presença digital sólida e profissional.

## ✨ Características do Projeto

- **Estética Editorial**: Design inspirado em revistas de luxo, com tipografia imponente e layout limpo.
- **Identidade Visual**: Paleta de cores baseada em Rosa Sofisticado (`#9E6B72`), Onyx (`#2d322f`) e Neutros Premium.
- **Totalmente Responsivo**: Experiência otimizada para Desktop, Tablets e Mobile.
- **Performance**: Construído com React + Vite para carregamento instantâneo.
- **Animações Fluidas**: Reveal effects ao scroll e interações de micro-estatísticas.
- **Mockups Integrados**: Slider interativo de projetos dentro de um mockup de iPhone.

## 🛠️ Tecnologias Utilizadas

- **React.js**
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)
- **Framer Motion** (Hooks de Scroll Reveal customizados)

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone [url-do-repositorio]
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

## 🌐 Deploy no Netlify

Este projeto está pronto para ser publicado no Netlify.

**Configurações de Build:**
- **Build Command:** `npm run build`
- **Publish Directory:** `dist`

O arquivo `netlify.toml` já está configurado para gerenciar redirecionamentos de rotas (SPA).
